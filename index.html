ЭЦН в координатах Сютера

Анализатор совмещает каталог ЭЦН и диаграммы Сютера: обзор Wh/Wm, сравнение каталожных H/N/η с восстановленными по ближайшей группе, и формулы для двух сценариев. Продление выполняется по выбранному диапазону расхода при alpha = 1.

Кривые Wh/Wm сопоставляют каталожные точки ЭЦН с эталонными диаграммами Сютера в координатах theta, Wh, Wm. Сплошные линии - эталонные группы Сютера, пунктир с открытыми маркерами - каталог выбранных ЭЦН.

Wh = (H/H*)/(alpha²+v²), где alpha=1 и v=Q/Q*.

Wm = (N/N*)/(alpha²+v²). В v1 трактуем Wm как нормированную мощность/момент по принятой формуле.

Фоновые зоны показывают диапазоны theta: 0..90° соответствует положительной подаче при alpha>0, 90..180° - отрицательной подаче при alpha>0, 180..270° - области отрицательной частоты/обратного вращения. В текущей модели продления alpha=1, поэтому фактически используется область 0..180°.

Сценарий 1: Каталог ЭЦН -> координаты Сютера

Исходные величины

Номинальная подача
Q* = rate_nom_sm3day

Берется из каталога ЭЦН, единицы: м3/сут.

Напор в Q*
H* = interp(H(Q), Q*)

Линейная интерполяция head_points по rate_points.

Мощность в Q*
N* = interp(N(Q), Q*)

Линейная интерполяция power_points по rate_points.

Переход к координатам Сютера

Режим v1
α = 1

Частота вращения положительная и равна номинальной.

Безразмерный расход
v = QQ*
Угол диаграммы
θ = atan2(α, v)
Нормированный напор
Wh = H / H*α2 + v2
Нормированная мощность
Wm = N / N*α2 + v2

Этот сценарий используется для переноса каталожных точек на диаграммы Сютера и выбора ближайшей группы по nq (SI).

Сценарий 2: Диаграммы Сютера -> продленные H/N/η

Обратный расчет из диаграмм Сютера

Диапазон расхода
v ∈ domain(compare)

Выбранный диапазон вкладки сравнения: авто, каталог, -1..+1 или -2..+2; шаг сетки около 0.025.

Значения диаграммы
Wh(θ), Wm(θ) @ Ns

Берутся с ближайшей группы Сютера по nq (SI).

Расход
Q = v · Q*
Напор
Hsuter = Wh(θ) · (α2 + v2) · H*
Мощность
Nsuter = Wm(θ) · (α2 + v2) · N*

КПД и константы

Перевод расхода
Qm3s = Q86400
КПД
ηsuter = ρ · g · Qm3s · HsuterNsuter · 1000
Принято для v1
ρ = 1000 кг/м3, g = 9.80665 м/с2

Этот сценарий нужен для продления в отрицательную область по дебиту и напору. Ограничение v1: отрицательную частоту вращения не моделируем, фиксируем alpha = 1.

Обозначения

Q*номинальная подача, м3/сут
H*напор в номинальной точке, м
N*мощность в номинальной точке, кВт
vбезразмерный расход: Q / Q*
θугол диаграммы: atan2(α, v)
Wh, Wmнормированные функции диаграмм Сютера
