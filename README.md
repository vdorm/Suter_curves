# ESP Suter Curve Analyzer

Локальный HTML-анализатор для сопоставления каталожных характеристик ЭЦН с диаграммами Сютера.

Проект можно открыть без установки Python, Excel-добавок или дополнительных пакетов: достаточно открыть файл `index.html` в браузере. Графики строятся через локальный файл `vendor/plotly.min.js`.

## Что внутри

- `index.html` - готовая интерактивная HTML-страница с уже встроенными данными ЭЦН и кривыми Сютера.
- `vendor/plotly.min.js` - локальная копия Plotly для построения графиков без интернета.
- `source_data/appendix_e_pump_characteristic_data_wide.csv` - оцифрованные данные диаграмм Сютера, оставлены для прозрачности источника.
- `source_data/ESP_json.db` - исходная база каталожных данных ЭЦН, оставлена для воспроизводимости.
- `suter_esp_calculation_check.xlsx` - Excel-файл для ручной проверки расчета по одному выбранному ЭЦН.
- `SUTER_ESP_ANALYZER_HANDOFF.md` - техническая записка с формулами, принятыми допущениями и идеями для продолжения разработки.

## Как открыть

Откройте файл:

```text
index.html
```

Если репозиторий опубликован через GitHub Pages, страница будет доступна как обычный сайт. Если открыть `index.html` прямо в интерфейсе GitHub, GitHub покажет исходный HTML-код, а не интерактивную страницу.

## Основные вкладки

### Кривые Wh/Wm

Сравнение каталожных точек ЭЦН с эталонными диаграммами Сютера в координатах:

```text
theta, Wh, Wbeta
```

Для удобства в интерфейсе также отображаются группы быстроходности Сютера `Ns = 25`, `147`, `261`.

### Сравнение ЭЦН

Детальная проверка одного выбранного ЭЦН:

- напор `H(Q)`;
- мощность `N(Q)`;
- КПД `eta(Q)`;
- сравнение каталожных точек с восстановленными значениями по ближайшей диаграмме Сютера;
- возможность смотреть расход как `Q/Q*` или как `Q, м3/сут`;
- режимы диапазона расхода, включая автоматический диапазон, который покрывает весь каталог выбранного ЭЦН и отрицательную область расхода.

### Формулы

Инженерное описание двух сценариев:

- переход от каталога ЭЦН к координатам Сютера;
- обратный расчет из диаграмм Сютера к продленным характеристикам `H`, `N`, `eta`.

В текущей версии принимается:

```text
alpha = 1
```

То есть частота вращения считается положительной и равной номинальной. Отрицательная область расхода учитывается через `v = Q/Q* < 0`.

## Важное уточнение по Wm / Wbeta

В исходных диаграммах Сютера второй коэффициент относится к моменту:

```text
Wbeta = beta / (alpha^2 + v^2)
```

где `beta` - нормированный момент.

В каталоге ЭЦН доступны точки мощности `N`, а не момента. Поэтому в текущей версии используется связь:

```text
N = omega * M
```

При `alpha = 1` нормированная мощность численно совпадает с нормированным моментом:

```text
N / N* = beta
```

Если в будущих версиях будет добавлена переменная частота или обратное вращение, формулу мощности нужно будет считать через:

```text
N_suter = alpha * beta_suter * N*
```

## Источники данных Сютера

Оцифрованные данные диаграмм Сютера взяты из:

M. Hanif Chaudhry, *Applied Hydraulic Transients*, 3rd Edition, Springer, 2013 / 3rd ed. 2014, ISBN 978-1461485377.

В книге приведены ссылки на исходные работы:

- Thomas, G. (1972), "Determination of Pump Characteristics for a Computerized Transient Analysis", Proc., First Inter. Conference on Pressure Surges, British Hydromech. Research Assoc., England, pp. A3-21 to A3-32.
- Donsky, B. (1961), "Complete Pump Characteristics and the Effect of Specific Speeds on Hydraulic Transients", Jour., Basic Engineering, Trans., Amer. Soc. of Mech. Engrs., pp. 685-699.

## Ограничения текущей версии

- Используются только три группы диаграмм Сютера: `Ns = 25`, `147`, `261`.
- Интерполяция между группами быстроходности не выполняется; выбирается ближайшая группа.
- Продление в отрицательную область выполняется при `alpha = 1`.
- База ЭЦН содержит обычные положительные каталожные характеристики, а не полноценные четырехквадрантные испытания.
- Расчет КПД использует воду: `rho = 1000 кг/м3`, `g = 9.80665 м/с2`.

## Публикация на GitHub Pages

Минимальный набор для публикации:

```text
index.html
vendor/plotly.min.js
README.md
```

Для большей прозрачности можно также оставить:

```text
source_data/
suter_esp_calculation_check.xlsx
SUTER_ESP_ANALYZER_HANDOFF.md
```

После загрузки в GitHub включите GitHub Pages:

```text
Settings -> Pages -> Deploy from a branch
```

Если `index.html` лежит в корне опубликованной папки, GitHub Pages откроет анализатор как обычный сайт.
